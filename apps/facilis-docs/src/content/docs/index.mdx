## What Facilis Does

Facilis helps inputs display structured values while keeping the formatting
logic reusable. A credit card number can group itself, a currency input can
pad cents on blur, and a date can reject impossible month/day values without
tying that behavior to one framework.

The core package defines what a format is. Adapter packages connect formats to
real inputs. First-party formats cover common fields, and testing helpers let
format behavior be checked without opening a browser.
