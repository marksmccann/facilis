Facilis is designed around **Format Definitions**: small, reusable definitions
that describe how a value is normalized, formatted, blurred, edited, selected,
and tested.

This comparison focuses on documented capabilities rather than ranking projects.
IMask, Cleave.js, and React Number Format are established tools with useful
ideas and real production histories. Facilis aims to cover the same everyday
formatting needs while making the format itself modular, composable, extendable,
and shareable.

## Why Format Definitions matter

A Format Definition is product logic, not just input wiring. You can create a
format once, share it across apps or packages, bind it to a DOM input, use it in
React, and test it without a browser.

```ts
import { defineFormat } from 'facilis';

export const productCode = () =>
    defineFormat({
        normalize(raw) {
            return raw.replace(/[^a-z0-9]/gi, '').slice(0, 8);
        },
        format(normalized) {
            return normalized.toUpperCase();
        },
    });
```

First-party formats follow the same idea. Import the group from
`facilis-formats`, or import only the formats your app needs.

```ts
import { currency } from 'facilis-formats/currency';
import { phoneNumber } from 'facilis-formats/phoneNumber';
```

## What Facilis is trying to make obvious

Facilis puts the Format Definition at the center:

- formats are reusable outside any one framework or adapter;
- formats can be imported one at a time instead of as one kitchen-sink bundle;
- custom formats can be shared like any other package-level function;
- adapters are thin and replaceable;
- normalize, format, blur, and edit behavior are named directly;
- cursor behavior can be handled with public selection helpers;
- format behavior can be tested without a browser.

That shape matters when a formatting rule starts in one input and later needs
to move into another UI surface, another adapter, a regression test, or a
first-party format package.

## When another tool may fit

Another input formatting tool may be a good choice when your app already uses
it successfully, when you need a mature mask feature Facilis has not added yet,
or when you want a framework-specific component API instead of a portable format
definition.

Facilis is aimed at teams that expect formatting behavior to become shared
product logic, not just input-local wiring.
