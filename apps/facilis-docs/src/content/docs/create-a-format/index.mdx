Create a custom format when a first-party format, `pattern()`, or `text()` does
not describe the behavior your field needs.

Creating a format starts with `defineFormat()`. Most formats are built from a
small pipeline:

- `normalize` extracts the semantic value from any display value.
- `format` builds the focused display value.
- `blur` applies formatting that should wait until the user leaves the field.
- `edit` hooks handle exceptional append, insert, and backward-delete behavior.

The layered format factories cover common format families when you want more
behavior out of the box. Reach for `defineFormat()` when a field needs behavior
outside those factory defaults.
