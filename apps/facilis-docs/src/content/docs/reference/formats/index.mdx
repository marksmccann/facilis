First-party formats cover common input shapes with reusable Facilis format
definitions. Use these when the field you need already has a named domain shape,
then drop down to `pattern`, `text`, or a custom format when the behavior is
more specific to your app.

## Package

```ts
import {
    creditCard,
    currency,
    date,
    ein,
    expirationDate,
    number,
    pattern,
    percent,
    phoneNumber,
    socialSecurityNumber,
    text,
    time,
    zipCode,
} from 'facilis-formats';
```

Use `facilis-formats` when you want ready-made format definitions instead of
building a custom one directly with `defineFormat()`.
